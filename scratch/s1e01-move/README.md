# S1E01 — หยองหยองเดินซ้าย-ขวา

เป้าหมาย: กดลูกศรซ้าย/ขวาแล้วหยองหยองเดินตาม ไม่กลับหัว และไม่หายเข้าขอบจอ

ทุกบั๊กในตอนนี้พังจริงใน Scratch 3.32.1 (ภาษาไทย) และแก้แล้วหายจริง

| ไฟล์ | เกิดอะไรขึ้น | วิธีแก้ |
|---|---|---|
| `starter.sb3` | หยองหยองยืนบนหญ้า ยังไม่มีโค้ด | — |
| `bug-noloop.sb3` | กดลูกศรค้างแล้ว **ไม่ขยับเลย** เพราะ "ถ้า" ทำงานแค่ครั้งเดียวตอนคลิกธง | ครอบด้วย **วนซ้ำตลอด** |
| `bug-flip.sb3` | เดินซ้ายแล้ว **กลับหัว** เพราะ "หันในทิศทาง -90" หมุนทั้งตัว | ใส่ **ตั้งรูปแบบการหมุนเป็น ซ้าย-ขวา** ใต้ธงเขียว |
| `bug-edge.sb3` | กดค้างจน **เดินหายเข้าขอบจอ** เหลือให้เห็นนิดเดียว | **ถ้า ตำแหน่ง x > 200 แล้ว ตั้งค่า x เป็น 200** (และ < -200 → -200) |
| `fix.sb3` | เดินซ้าย-ขวาได้ ตัวตั้งตรง หยุดที่ขอบ | — |

ดูทีละขั้นว่าแก้อะไร:

```bash
git diff s1e01-bug1 s1e01-bug2 -- scratch/s1e01-move/project.json   # แก้บั๊ก 1 (+ เจอบั๊ก 2)
git diff s1e01-bug3 s1e01-fix  -- scratch/s1e01-move/project.json   # แก้บั๊ก 3
```

`project.json` คือโค้ดของสถานะล่าสุดในรูปที่อ่านด้วย `git diff` ได้ (สร้างด้วย `tools/sb3.py dump`)
